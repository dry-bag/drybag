Notes sync between machines on its own. A machine whose machine file says `[sync] enabled = true` (which `stayfixed setup --overlay` writes for an overlay it renders or creates) now commits the overlay's memory notes, takes in the other machines' and pushes its own from Claude Code's `SessionStart`, `Stop` and `SessionEnd` hooks, through a detached job: only memory notes move, a secret scan runs before every commit and push, and `stayfixed doctor` gains a `sync` row (fifteen rows now). A machine whose file does not say so runs nothing new. See "Note sync" in `docs/cli.md`.
