An overlay can now hold tags: a `groups/<tag>/` directory shaped like `common/` (values, rules, Claude Code files, Codex rules, notes under `groups/<tag>/memory/`), shared by every project that lists it as `tags = ["<tag>", ...]` in its `projects/<name>/project.toml`. One precedence holds everywhere, the later plate winning: `common/`, the tags in list order, `projects/<name>/`, then the machine file. A tag's notes reach the session as the composed store's group `tag-<tag>`; values and rules follow the next session, and the delivered files, allow rules and store links the next `stayfixed attach`. `stayfixed doctor` warns when two tags hold one name, or when a listed tag has no directory. A repository cannot name a tag: tags are read only from the record of the project this machine binds the checkout to.
