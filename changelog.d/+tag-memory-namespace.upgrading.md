A directory of a project's `memory/` in the overlay whose name starts with `tag-` is no longer linked into the composed store, because `tag-<tag>` now names a tag's notes; `stayfixed doctor` names each such directory. Rename it and run `stayfixed attach` again. `stayfixed attach` also stops, with nothing written, when the overlay's `projects/<name>/project.toml` exists but cannot be read (a merge conflict left in it, for example); mend it and run `attach` again. Sessions go on reading the rest of the overlay meanwhile.
