`stayfixed attach` now names each `.codex/rules/` file it placed earlier that your overlay no longer holds, for example after you take a tag off a project, and leaves it where it is; before, the copy stayed unmentioned, and Codex went on reading it as a standing instruction. `stayfixed detach` removes such a copy only while it is untracked and holds the bytes `attach` wrote, and leaves and names any recorded copy whose bytes changed.
