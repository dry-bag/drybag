`stayfixed attach` now keeps its ledger of what it added in the git common directory, `stayfixed/attach.json` beside the binding id, where a branch cannot write it; before, it sat in `.stayfixed/local/attach.json` in the working tree, and a branch could commit one that made `detach` and a re-attach remove files and allow rules you wrote. The old file is neither read nor removed, so you can delete it. Run `stayfixed attach` again to rebuild the ledger. `stayfixed detach` does not remove the allow rules and the directories an attach merged before the move: take those out of `.claude/settings.local.json` and the checkout by hand.
