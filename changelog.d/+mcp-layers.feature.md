A plate of the overlay (`common/`, a tag, a project, or a `machines/<name>/` sub-plate) can hold `claude/mcp.json`. `drybag attach` delivers the servers it defines at Claude Code's local scope through `claude mcp add-json`, takes back the ones the overlay no longer serves, and writes `deniedMcpServers` for a name a plate switches `"off"`, naming each on its screen; `drybag detach` takes them all back, and `attach --check` lists what would change without running `claude`. A server Claude Code refuses stays unsettled and makes `attach` exit 1 until a later run delivers it. An `mcp.json` that is there and cannot be read, or an MCP ledger this drybag cannot read, is said, and the run then changes no server and no deny entry. `drybag doctor`'s `attached` row names each server with the plate that defines it, and warns of each one `attach` has yet to deliver or take back, without printing any value.
