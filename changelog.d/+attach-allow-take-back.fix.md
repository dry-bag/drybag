`stayfixed attach` now takes back an allow rule it merged earlier when your overlay no longer grants it, for example after you remove a tag from a project, and says each one as `allow rule withdrawn` (`allow_withdrawn` in `--json`); before, such a rule stayed in `.claude/settings.local.json` until `stayfixed detach`. A rule you added by hand, which the attach ledger does not name, stays; the ledger is a file in the checkout, so a branch that commits one can make a later `attach` or `detach` take a rule away.
