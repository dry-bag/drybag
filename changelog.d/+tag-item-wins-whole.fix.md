A skill or agent that two plates of your overlay hold (`common/`, a tag, the project) is now delivered whole from the later one. Before, `stayfixed attach` merged the two directories file by file, so a file only the earlier plate held, such as a helper script, stayed beside the later plate's `SKILL.md`. A Codex rule file a later plate replaces now also takes that plate's place in the order the files are listed.
