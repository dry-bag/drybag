A new linked worktree of a checkout bound to an overlay project now gets the owner-held files from the overlay's `projects/<name>/checkout/` (an `AGENTS.md`, a `CLAUDE.md`, a `stayfixed.toml`) when its first session starts, so you no longer copy them by hand. Only regular files are placed, never a `.env*` file or `settings.local.json`, and nothing is placed over a name the worktree already has.
