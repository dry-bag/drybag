A plate's `claude/mcp.json` can say `"*": "off"`: `drybag attach` then writes `allowedMcpServers` in the main checkout's `.claude/settings.local.json`, listing only the servers the plates switch on (served, or `"on"` with no definition for one defined elsewhere), or `[]`, which on Claude Code 2.1.325 loads no MCP server, the claude.ai connectors and plugins' servers included. Every other key in the file stays. A key drybag did not write is left as it is and said, and an entry you add to drybag's key stays yours; only the names drybag added are recorded in `drybag/attach-mcp.json`, and a later `"*": "on"` or `drybag detach` takes them back. It fails closed: a misspelt `"*"` is read as `"off"`, an unreadable `mcp.json` beside a `"*": "off"` writes `[]`, and an allowlist that cannot be written makes `attach` exit 1. `attach --check` lists the allowlist it would write or take back (`mcp_allowlist`, `mcp_allowlist_withdrawn`), and `drybag doctor`'s `attached` row names it with the plate that asks for it and warns while `attach` has yet to write or take it back.
